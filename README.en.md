# NixOS Config

> 🇬🇧 English version — [🇫🇷 Version française ici](./README.md)

My personal NixOS configuration, built and refined for my daily use on my ZenBook 13.

This isn't a generic template or a tutorial repo: it's **my own** config, shaped by my own choices, needs, and taste for personalization. It keeps evolving over time, more like an ongoing personal project than a "finished" product.

---

## Why this exists

I moved to NixOS after using CachyOS, wanting a system that's **fully declarative and reproducible**: my entire system configuration is version-controlled here, so if my disk fails or I switch machines, I can rebuild my exact environment in a few commands instead of reinstalling everything by hand.

Beyond the practical side, it's also a playground for understanding how a modern Linux system really works under the hood: disk encryption, boot process, hardware management, security, and desktop environment.

---

## Hardware

- **Machine**: ASUS ZenBook 13
- **GPU**: Intel Iris Xe (`xe` driver, not `i915`)
- **Audio chipset**: Intel Tiger Lake (SOF)

---

## Tech stack

| Component | Choice | Why |
|---|---|---|
| **Bootloader** | `systemd-boot` | Simple, fast, native UEFI |
| **Encryption** | LUKS + TPM2 (`systemd-cryptenroll`) | Secure automatic unlock at boot |
| **Filesystem** | Btrfs with subvolumes | Snapshots and flexibility |
| **Desktop environment** | KDE Plasma 6 + SDDM | Full-featured and highly customizable |
| **Shell** | Fish | More pleasant for daily use than Bash |
| **Authentication** | Howdy (facial recognition) | Fast unlock, with a specific PAM exclusion to avoid conflicts with `polkit` |
| **Theme** | Sweet (global KDE theme) | Personal aesthetic choice |

## Repo structure

```
.
├── configuration.nix           # Main entry point
├── hardware-configuration.nix  # Hardware config generated by NixOS
└── modules/
    ├── system.nix              # Boot, kernel, GPU, network, locale
    ├── services.nix            # System services (Plasma, audio, Howdy...)
    ├── users.nix                # User accounts
    └── programs.nix            # Programs, Fish shell, Git
```

My **Home Manager** configuration (user packages and dotfiles) lives in a separate repo: **[Home-Manager-Config](https://github.com/tbracquart/Home-Manager-Config)**. This is a deliberate split, to keep a clean boundary between system config (`root`) and user config (`thibaut`).

Each module handles a specific concern, so the config stays easy to evolve without breaking everything else.

## A few problems solved along the way

- **3-minute boot delay** caused by a misplaced semicolon in a LUKS UUID
- **Howdy / polkit conflict** resolved with a targeted PAM exclusion
- **Known audio bug on Tiger Lake + SOF** after suspend, with a documented workaround
